# Embodied Cognitive Mapping 基本操作マニュアル

## 1. このデモでできること

Embodied Cognitive Mappingは、認知科学の理論や概念を3次元空間に配置し、位置・形・色・説明を比較しながら考えるためのツールです。

公開デモはブラウザだけで動作します。編集結果は使用しているブラウザに保存されます。

> GitHub Pages版は **Local mode** です。リンクを共有した人どうしで編集内容は自動同期されません。共同編集にはSupabaseを設定した本体版を利用してください。

## 2. 画面の見方

| 領域 | 役割 |
| --- | --- |
| 上部 | Room、View、保存・JSON操作 |
| 中央 | 3D概念マップ。球体を直接操作する場所 |
| 左上 Layers | 理論群を重ねて表示・非表示・透明度を調整する場所 |
| 右側 Object Editor | 選択した概念の詳細な編集 |

## 3. はじめ方

1. デモを開きます。
2. 中央の球体をクリックして、編集したい概念を選びます。
3. 右側のObject Editorで座標、形、色、説明を調整します。
4. 必要に応じて上部の `Save` を押します。

## 4. 3D画面の操作

### カメラ

- 空白部分をドラッグ: 視点を回転
- マウスホイール: 拡大・縮小
- 右ドラッグ: 視点を平行移動

XYZの軸線は、原点から正方向・負方向の両側に同じ長さで伸びています。

### 2次元平面へ切り替える

画面上部の `3D / XY / YZ / XZ` で表示視点を切り替えます。

- `XY`: Z方向から見るXY平面
- `YZ`: X方向から見るYZ平面
- `XZ`: Y方向から見るXZ平面
- `3D`: 通常の立体表示へ戻る

平面ビューでも球体の選択、Move、Shape、Connectは使用できます。

### 概念（球体）を配置する

1. 球体を左クリックしたままドラッグします。
3. 通常のドラッグでは、画面と平行な面の上を自然に移動します。
4. `Shift` を押しながらドラッグすると、奥行き（Z方向）を移動します。上へ動かすとZが増え、下へ動かすと減ります。

ドラッグ中はカメラ回転が停止し、右側のX/Y/Z値も同時に更新されます。球体のラベルも一緒に移動します。

### 形を変える

- 球体をクリックすると、周囲に赤（X）・緑（Y）・青（Z）の変形ハンドルが現れます。各色の丸いハンドルをドラッグすると、その方向だけを伸縮できます。
- 右側の `Scale X / Y / Z` と `Base size` は数値での微調整にも使えます。

### 関係線を作る

- 操作モードの切替は不要です。`Shift` を押しながら2つの球体を順にクリックします。
- 2つ目を選ぶと関係線が直ちに作られ、右側で関係種別・ラベル・比較次元を編集できます。
- 最初の球体は水色で強調表示されます。`Esc` または空白部分のクリックで接続をキャンセルできます。同じ球体を2回選んでも接続は作られません。
- 線または中点のラベルをクリックすると選択、ラベルをダブルクリックすると3D画面上で直接編集できます。`Enter`またはフォーカスアウトで保存、`Esc`でキャンセルです。複数行は `Shift + Enter` で入力できます。
- 選択した線は `Delete` / `Backspace` でも削除できます。

### Thinkerカードを見る

球体をダブルクリックすると、その理論の代表的な研究者をカード表示します。複数の研究者を登録した概念では左右ボタンで切り替えられます。カードには人物名、年代、役割、代表メッセージ、主要文献が表示されます。

## 5. Object Editorでの編集

### 位置

- X / Y / Z: 数値による精密な位置編集
- `Reset position`: 原点に戻す
- 3D画面の直接ドラッグとXYZ数値入力を併用できます。

### 色とカテゴリー

1. カテゴリーのプルダウンを選びます。
2. カテゴリーを変えると、そのカテゴリーに設定された既定色が適用されます。
3. 必要なら12色の丸いスウォッチから個別の色を選びます。
4. 特殊な色が必要なときだけ `Custom color…` を押します。
5. `Opacity` は色とは独立した透明度です。

`Category palette` を開くと、各カテゴリーの既定色を変更できます。

### Layer

左上の `Layers` パネルでは、各Layerのチェックを外して非表示にしたり、Opacityで一括して薄く表示できます。Layerを追加後、Object EditorのLayerプルダウンで各球体の所属先を選びます。Layerを削除しても球体は消えず、残っているLayerへ移動します。

### 説明・複製・削除

- `Description`: 概念の説明を編集
- `Duplicate`: 選択中の概念を複製
- `Delete`: 選択中の概念を削除
- `+ Add object`: 新しい概念を追加

## 6. 軸ラベルを変える

X / Y / Zの各軸には、`− end` と `+ end` の2つのラベルがあります。たとえばX軸を「低次」から「高次」と読む場合、`− end` を `低次`、`+ end` を `高次` と設定します。

次のどちらでも編集できます。

- 3D画面上の各軸の両端ラベルをダブルクリック
  - `Enter`: 確定
  - `Esc`: キャンセル
  - フォーカスを外す: 確定
- 右側の `Axis labels` 欄で直接入力

軸ラベルはViewごとに独立して保存されます。

## 7. Viewを使い分ける

Viewは同じ概念群を異なる研究者・目的の配置で比較するためのタブです。

- タブをクリック: Viewの切り替え
- `+`: 新しいViewを作成
- `Rename`: 現在のViewの名称を変更
- `Duplicate`: 現在のViewを複製して別案を作成
- `Delete`: 現在のViewを削除

`read only` と表示されたViewは直接編集できません。比較用の基準配置として使えます。

### 操作を元に戻す

Viewバーの `↶ Undo`、または `Ctrl + Z`（macOSでは `Cmd + Z`）で直近の変更を元に戻せます。最大50件までの編集履歴を保持します。名称や説明などのテキスト入力中は、ブラウザ標準の文字入力Undoが優先されます。

## 8. 保存と共有

### Save

`Save` は現在の編集結果を保存します。GitHub Pages版ではブラウザのLocal Storageに保存されます。同じブラウザで開き直せば編集内容が残ります。

### JSON Export / Import

- `Export`: 現在のViewをJSONファイルとして書き出す
- `Import`: JSONファイルを読み込み、別Viewとして追加する

別のPCや共同研究者へ配置を渡す場合は、JSON Export / Importを使ってください。

### Room

- `New room`: 新しいRoom IDを作成
- `Join`: Room IDまたはRoom URLを入力
- `Copy URL`: 現在のRoom URLをコピー

GitHub Pages版では、Room URLを共有しても内容は同期されません。同期が必要な場合はSupabaseを設定してください。

## 9. まず試す操作

1. `Embodied Cognition` を選ぶ。
2. `Move` のまま球体をドラッグし、理論間の距離を調整する。
3. `Shift + drag` で奥行きを変える。
4. カテゴリーを `Embodied / Embedded` にし、黄色のスウォッチを選ぶ。
5. 球体をダブルクリックしてThinkerカードを確認する。
6. `Connect` で比較したい2つの理論を選び、関係と比較次元を記録する。
7. X軸ラベルをダブルクリックして、研究目的に合う対立軸へ変更する。
8. `Duplicate` でViewを複製し、別の解釈を並行して試す。
9. よい配置ができたら `Export` でJSONを保存する。

## 10. 困ったとき

- 球体が動かない: `Move` モードを選び、read onlyではないViewを開いているか確認します。
- 視点が動いてしまう: 球体そのものをつかんでドラッグしてください。空白部分のドラッグはカメラ操作です。
- 他の人の編集が見えない: GitHub Pages版は共同編集に対応していません。Supabaseを設定した本体版を使用してください。
- 編集を別の端末へ渡したい: `Export` でJSONを保存し、相手側で `Import` します。
